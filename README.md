## Featured Project

### 🏗️ EquipRent: Equipment Rental Marketplace

A full-stack rental marketplace where customers discover, favorite and book equipment, owners manage their listings and bookings, and admins oversee the whole platform. Payments run through Stripe Checkout, and the backend secures every request with JWT verification and role-based middlewares (`verifyToken`, `verifyRenter`, `verifyOwner`, `verifyAdmin`).

**Highlights:**
- Separate Customer, Owner and Admin dashboards with role-based access control
- Equipment search, filtering and sorting, plus favorites and rental history
- Stripe Checkout with payment verification and automatic booking status updates
- Owner earnings and admin booking analytics, with admin approval of listings

**Stack:** Next.js · TypeScript · Tailwind CSS · Express.js · MongoDB · Better Auth · JWT · Stripe

[Live Demo](https://equiprent-client-rk.vercel.app/) · [Frontend Code](https://github.com/rezasdsju/equiprent-client) · [Backend Code](https://github.com/rezasdsju/equiprent-server)
